# Ответы на пять бизнес-вопросов

Расчёт непосредственно по исходным CSV Olist, закреплённым в `scripts/download_data.sh` и `scripts/olist.sha256` (Olist commit d9e49802f3e92d09ee94ab9ccc5e457f207a8959). Это независимая проверка исходных данных, а не результат запуска DWH/dbt.

## Воспроизведение

Из корня репозитория, Python 3, без внешних библиотек:

```sh
bash scripts/download_data.sh
python3 analysis/business_questions/answer_raw.py data analysis/business_questions/results
```

Деньги в исходном Olist — бразильские реалы (BRL), не рубли. Суммы считаются Decimal, без float. Времена исходника без часового пояса; месяц берётся из order_purchase_timestamp без конвертации в UTC.

## 1. Продажи по месяцам

За сентябрь 2016 — август 2018: **24 месяца, 96 478 доставленных заказов, 13 221 498,11 BRL** выручки без доставки. Ноябрь 2016 включён явно: 0 заказов, 0 выручки. Пик — ноябрь 2017: 7 289 заказов, 987 765,37 BRL.

Полный ответ: [monthly_sales.csv](results/monthly_sales.csv). Выручка = SUM(order_items.price), только order_status = delivered; заказы = COUNT DISTINCT order_id. Календарь создаётся независимо от наличия продаж.

## 2. Топ-10 продавцов

Полный ответ с ID, городом, штатом, количеством заказов и единиц: [top_sellers.csv](results/top_sellers.csv).

Первый — `4869f7a5dfa277a7dca6462dcf3b52b2`, Guariba / SP: **226 987,93 BRL**, 1 124 заказа, 1 148 единиц. Далее Lauro de Freitas / BA — 217 940,44; Ibitinga / SP — 196 882,12 BRL.

Каждому продавцу относится только price его позиций в доставленных заказах. Один заказ с несколькими продавцами считается у каждого участвующего продавца; суммы заказов целиком продавцам не приписываются. Здесь и в вопросах 3–5 дополнительный фильтр периода не задан.

## 3. Средний чек

**159,88 BRL** с доставкой. Сначала SUM(price + freight_value) по каждому доставленному заказу, затем среднее по 96 478 заказам. В среднем **1,142198 строки и столько же единиц товара на заказ**: в Olist каждая строка order_items представляет одну единицу, отдельной колонки quantity нет.

## 4. Повторные покупки

**96 096 покупателей; 2 997 совершили минимум два заказа; доля 3,1188% ≈ 3,12%.** Ключ — customer_unique_id; customer_id меняется между заказами. Для этого вопроса учитываются все статусы, поэтому результат означает повторное оформление заказа, а не обязательно вторую завершённую покупку. Таблица customers в этой выгрузке содержит 99 441 строку — по одной на заказ.

## 5. Категории

**74 группы**, включая `unknown` для пустой категории. Лидер — **beleza_saude** (красота и здоровье): **1 233 131,72 BRL**, доля **9,3267%**. Затем relogios_presentes — 1 166 176,98 (8,8203%), cama_mesa_banho — 1 023 434,76 (7,7407%).

Все группы и доли: [categories.csv](results/categories.csv). Выручка = SUM(price) доставленных позиций; знаменатель доли — 13 221 498,11 BRL, включая unknown. Сумма категорий совпадает с месячной выручкой. Округлённые доли могут в сумме не дать ровно 100%.

## Проверки

Исходник: 99 441 заказ, 112 650 позиций. Все 96 478 доставленных заказов имеют позиции. Общая выручка по категориям и месяцам совпадает: 13 221 498,11. Все пять контрольных значений задания воспроизведены. Платежи и отзывы не присоединяются к позициям, поэтому не размножают суммы.

Машиночитаемые итоги: [summary.json](results/summary.json). Пример ORDER-01 с суммами в рублях на слайде про JOIN — условная иллюстрация, к валюте Olist отношения не имеет.
