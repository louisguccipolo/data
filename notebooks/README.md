# ML-ноутбуки Olist

1. **`01_delivery_eta.ipynb`** — срок от подтверждения оплаты до получения, для пары продавец × город × день. EDA, исторические и константные бейзлайны, CatBoost, временная валидация, p50/p90, холодный старт, сохранение моделей и пакетный прогноз.
2. `train_from_marts.ipynb` — обзор всех готовых витрин и технические примеры для остальных задач.

Запуск из корня проекта:

```bash
.venv/bin/python -m pip install -r marts/requirements.txt
.venv/bin/python -m jupyterlab notebooks/01_delivery_eta.ipynb
```

Используйте Python из `.venv`. Ноутбук доставки содержит выполненные ячейки и графики; его можно просмотреть без повторного обучения. `Run All` воспроизводит эксперимент, обновляет `models/delivery_eta/` и `reports/delivery_eta/`.

Признаки зависят от пары и даты. Конкретные свойства заказа не используются. Обучающие и тестовые строки относятся к отдельным заказам, поскольку у них разные фактические сроки; прогноз при этом один на всю пару в день. Пример полной ночной сетки выполняется порциями; в обычном запуске сохраняется демонстрационная порция из 5 000 пар.

`marts/delivery_features.py` задаёт одинаковую обработку признаков для обучения и применения. `marts/delivery_batch.py` читает сохранённую модель и умеет строить признаки из локальных Parquet. Когда будут готовы SQL-витрины, передавайте их результат в `DeliveryModel.predict(pair_features)`.
